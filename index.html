Business trade-off: In churn prediction, False Negatives (missing a churner) are substantially more costly than False Positives (offering a retention perk to a loyal customer). Random Forest achieved 99.05% recall, minimizing missed customer exits.

Architecture & ML Workflow

This application is the official modern web interface for the Customer Churn Prediction System. Model inference is executed via a Python REST service loaded with the serialized Phase 4 Random Forest model (churn_model.pkl) and categorical encoders.

Dataset Reference Numbers:
  • Phase 2 Testing Dataset: 64,374 customer records (30,493 churned, 33,881 retained).
  • Phases 3 & 4 Consolidated Modelling Dataset: 442,211 unique customer records.
  • Selected Model: Random Forest Classifier (150 estimators, max depth 10, random state 42).
  • Reported Test Accuracy: 99.35% (Precision: 0.9981, Recall: 0.9905, F1: 0.9943).
